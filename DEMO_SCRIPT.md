# DevCollab Demo Video Script

Target length: 3-5 minutes.

1. Open the deployed DevCollab frontend and show the URL.
2. Login with `imran@devcollab.demo / DevCollab@123`.
3. Show the workspace dashboard, seeded projects, completion score, and live member presence.
4. Open a second browser/incognito window, login with `trivikram@devcollab.demo`, and join the same project.
5. Move a task on the Kanban board in the first browser.
6. Show the second browser receiving the task update without refresh.
7. Open a task discussion, add a comment with `@trivikram`, and show the notification.
8. Open Wiki, edit Architecture Notes, save, and show version count increasing.
9. Open Snippets, search `socket`, copy a snippet, and add one new snippet.
10. Open AI, generate a blocker or standup report.
11. Paste code into the AI Code Reviewer and show score plus suggestions.
12. Show Activity Feed recording the actions.
13. Open Plan tab and click the sandbox Pro upgrade.
14. End by showing the public GitHub repository and README.

Closing line:

> DevCollab replaces scattered student team tools with one live project workspace: tasks, docs, snippets, activity memory, and AI assistance in one deployable app.
