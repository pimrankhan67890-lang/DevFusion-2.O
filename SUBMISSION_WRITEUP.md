# 100-200 Word Submission Write-Up

DevCollab is a unified collaboration workspace built for student developer teams during hackathons and project sprints. Instead of splitting work across GitHub, Notion, Slack, and separate task boards, DevCollab brings the core workflow into one real-time project operating system. Teams can manage Kanban tasks, track live project presence, discuss work with mention notifications, maintain a project wiki, store reusable code snippets, and review project activity from one dashboard.

The MVP is implemented as a React + Vite frontend with an Express and Socket.IO backend. Task movement, comments, activity updates, and presence are broadcast live to connected users, proving true collaboration rather than static task tracking. DevCollab also includes an AI project assistant for summaries, blocker reports, standups, and task breakdowns, plus an AI code reviewer that scores snippets and gives actionable feedback. Seeded demo accounts, judge-friendly data, and a clean light UI make the submission easy to test. The result is a focused, original MVP that demonstrates product thinking, real-time engineering, and practical AI assistance for developer teams.
